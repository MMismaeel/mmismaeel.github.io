## Usman Shawls Centre - Static Website

Open `index.html` in a browser. All pages are in `pages/`. Assets live under `assets/`.

- 10 pages included: Home, About, Products, Collections, Gallery, Custom Order, FAQ, Testimonials, Contact, Store Locator.
- Edit copy in each HTML file. Replace images in `assets/images/` and reference them from pages.

Deployment: host the folder on any static host (GitHub Pages, Netlify, Vercel, or your own server).
